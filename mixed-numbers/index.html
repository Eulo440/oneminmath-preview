Mixed number practice

A mixed number is a whole number and a fraction together, like 3 1/2. Fractions Level 3 in One Minute Math is built around them: problems like 94 2/3 + 45 1/2 and 52 1/4 − 18 2/3, where you have to regroup or borrow.

Add mixed numbersSubtract with borrowing

How to type a mixed number answer

Mixed-number problems show three boxes: the whole number on the left, then the top and bottom of the fraction. Each box jumps to the next by itself once it has enough digits, so for 140 1/6 you just type 1 4 0 1 6. Answers must be in simplest form: 3 1/2, not 7/2 or 3 2/4.

Adding mixed numbers

  1. Add the whole numbers: 94 + 45 = 139.
  2. Add the fractions with a common denominator: 2/3 + 1/2 = 4/6 + 3/6 = 7/6.
  3. If the fraction is more than 1, carry it: 7/6 = 1 1/6, so the answer is 140 1/6.

Subtracting with borrowing

For 52 1/4 − 18 2/3: the fractions become 3/12 − 8/12, which is too small, so borrow 1 from 52: 51 15/12 − 18 8/12 = 33 7/12.
